# Natural-Event-Dashboard
Natural event dashboard project

## Instruction for deploy: 

### 1. Download the code to your local PC

​	You can select "<> Code" and download the zip to local then depress it, or you can clone the code locally. 

### 2. Run the Main class

​	Under src/main/java/app/Main run the Main.java and the window will automatically pops out for you.



## Instruction for App using:

### 1: Search the event 

​	By selecting Event Categories, Status, Past days(How many days ahead from today) and Amount Limit. Then press "Search". Desired events will pop out for you.

### 2: Add to Favourite

​	Select any event you want to temporarily save while viewing search view, press "Add To Favourite"

### 3: View Frequency Chart

​	Clicking "View Frequency Chart" will give you a bar graph based on the events existing on the search view. X-axis: date. Y-axis: frequency. It will self adjusted x-axis from the minimum date to maximum date.

### 4: Time-Series Analytics

​	Click "Time-Series Analytics" to see the Time-Series Analytics based on the events existing on the search view.
